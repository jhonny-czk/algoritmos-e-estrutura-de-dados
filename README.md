## 📖 Sobre

Este projeto consolida implementações modulares de algoritmos clássicos e estruturas de dados fundamentais. O objetivo central é aliar o rigor teórico (análise assintótica e complexidade de tempo/espaço) à experimentação prática por meio de exercícios, benchmarks e códigos comentados.

---

## 🎯 Objetivos

- **Compreensão Teórica:** Dominar conceitos de complexidade temporal e espacial ($O$, $\Omega$, $\Theta$).
- **Implementação Eficiente:** Construir estruturas de dados lineares e não lineares a partir do zero.
- **Resolução de Problemas:** Praticar com exercícios que simulam desafios reais de engenharia de software e computação.
