Objetivos

Compreender os principais conceitos de algoritmos e estruturas de dados.

Desenvolver soluções eficientes para problemas computacionais.

Analisar a complexidade temporal e espacial de algoritmos.

Implementar e comparar diferentes estruturas de dados.

Aplicar técnicas clássicas de busca, ordenação e manipulação de dados.

Desenvolver raciocínio lógico e capacidade de resolução de problemas.
